 Since this version uses **Framework-Dependent Deployment**, make sure your system meets the following requirements before running the launcher:

1. **.NET Runtime**:
   - You must have **[.NET 10.0 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)** or a later version installed locally.
2. **Java Runtime Environment (JRE)**:
   - Running Minecraft itself requires the Java version corresponding to the game version.
3. **Operating System Support**:
   - **Windows**: Windows 10 / 11 (64-bit)
   - **Linux**: x86_64 architecture Linux distro (like Arch Linux, Ubuntu, Debian, etc., recommended with Wayland/X11 desktop environment)
